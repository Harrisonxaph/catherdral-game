VESPER — Cathedral of Ash (iPhone + Android Web App)

1. Upload the ZIP file VESPER_Cathedral_of_Ash_PWA.zip to https://app.netlify.com/drop.
2. Open the new HTTPS website address Netlify gives you.
3. On iPhone (Safari): Share > Add to Home Screen > Add.
4. On Android (Chrome): Three-dot menu > Install app / Add to Home screen.
5. Open the game once while online, and wait for OFFLINE READY on the title screen.
6. After that, you can reopen it without an internet connection.

To update an existing Netlify game, upload this ZIP as a new deploy for the same site,
rather than creating a new project. Existing runs' local records are kept for that
website address; a different site address has a separate record.

Your best score is stored on each device separately. No cloud sync.
No App Store or Play Store submission required.
